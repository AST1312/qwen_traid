# Портфельный утренний мониторинг

Ежедневная проверка инвестиционного портфеля **один раз утром по будням в 10:15 MSK**.
Портфель формируется автоматически из PDF-отчёта брокера (поддерживаются отчёты в формате, аналогичном ТБанку / Т-Инвестициям).
Ловит три вещи: **понижение рейтинга**, **плохую отчётность** и **аномальный взлёт для фиксации прибыли**.
Результат — отчёт в `reports/` и сообщение в Telegram.

## Что уже сделано

| Артефакт | Что это |
|---|---|
| `portfolio.md` / `portfolio.csv` | список портфеля: позиции, номиналы, купоны, оферты, оценка и доли |
| `data/portfolio.json` | машинный список с площадками MOEX, эмитентами и ключевыми словами |
| `reports/YYYY-MM-DD_morning.md` | утренняя сводка (человекочитаемая) |
| `reports/YYYY-MM-DD_alerts.json` | те же события в JSON: severity, category, метрики по каждой бумаге |
| `reports/latest.md` / `latest.json` | последняя сводка (то, что открывается в чате) |
| `config/config.json` | пороги, расписание, источники, доставка |
| `config/secrets.env` | токен Telegram и chat_id (**создаётся вами**, образец рядом) |
| `logs/`, `state/` | логи запусков, история метрик, дедупликация новостей, статус планировщика |

## Состав портфеля

Портфель описывается файлом `data/portfolio.json` (создаётся автоматически из вашего брокерского отчёта).
Пример структуры — в `data/portfolio.example.json`.

### Поддерживаемые классы активов

| Класс (`class`) | Что это | Источник котировок |
|---|---|---|
| `share` | Акции РФ (MOEX) | MOEX ISS |
| `foreign_share` | Иностранные акции | Yahoo Finance |
| `corp_bond` | Корпоративные облигации | MOEX ISS |
| `ofz` | ОФЗ и субфедеральные выпуски | MOEX ISS |
| `foreign_sovereign` | Суверенные облигации других стран | Yahoo Finance |
| `fund` | БПИФ на акции/облигации | MOEX ISS |
| `fund_mm` | БПИФ денежного рынка (квази-кэш) | MOEX ISS |
| `frozen` | Заблокированные / без торгов | — (только новости) |

### Пример портфеля (из `data/portfolio.example.json`)

```
Акции РФ:       Сбербанк 200 шт, Лукойл 15 шт
ОФЗ:            ОФЗ-26230 25 шт (дюрация ~9 лет)
Корп. облигации: РЖД 001P-19R 20 шт (оферта 2027)
БПИФ ден. рынка: TMON 5000 паёв
Иностр. акции:  Alibaba (9988.HK) 50 шт — Yahoo Finance
Заблокировано:  Vipshop ADR 100 шт — только новости
```

### Как формируется `portfolio.json`

```
PDF брокерского отчёта
       │
       ▼
parse_report.py     →  data/holdings_raw.json   (парсинг PDF, позиции + сделки)
       │
       ▼
build_portfolio.py  →  data/portfolio.json      (обогащение: площадки MOEX,
                                                  номиналы, купоны, оферты,
                                                  эмитенты, ключевые слова)
       │
       ▼
make_portfolio_doc.py → portfolio.md + portfolio.csv  (человекочитаемые таблицы)
```

### Особенности

- **Облигации в USD/CNY с расчётами в RUB** — оценка пересчитывается по курсу MOEX, Z-спред к рублёвой кривой может быть отрицательным (это нормально).
- **Бумаги с `@` в коде СПБ** (например `TMON@`) автоматически маппятся на MOEX-тикеры без `@`.
- **Заблокированные позиции** (`class: frozen`) исключаются из оценки портфеля, но по ним продолжают сканироваться новости.

## Правила срабатывания

| Событие | Порог (пресет «строгий») | Severity |
|---|---|---|
| Взлёт за день | ≥ **+8%** | 🚀 фиксация |
| Взлёт за 5 сессий | ≥ **+20%** | 🚀 фиксация |
| Статистическая аномалия | ≥ **3σ** дневной волатильности (при движении ≥3%) | 🚀 фиксация |
| У 52-недельного максимума | в пределах 3% + неделя ≥ +10% | 🔵 инфо |
| Понижение рейтинга / негативный прогноз / отзыв | АКРА, Эксперт РА, новости | 🔴 критично |
| Дефолт, техдефолт, реструктуризация, банкротство | по эмитенту | 🔴 критично |
| Плохая отчётность | убыток, падение прибыли/выручки/EBITDA, снижение прогноза, отмена дивидендов | 🟠 предупреждение |
| Кредитный стресс облигации | цена −2% за день / −4% за неделю | 🟠 предупреждение |
| Расширение спреда | Z-спред +100 б.п. за сутки, доходность +150 б.п. | 🟠 предупреждение |
| Резкое падение акции | −6% за день | 🔵 инфо (алерт выключен) |
| Календарь | купон / оферта / погашение в ближайшие 14 дней | 🔵 инфо |

Пороги меняются в `config/config.json` → `thresholds`. Ослабить/усилить чувствительность можно без правки кода.

### Защита от ложных срабатываний
- Ключевые слова ищутся **по границам слов**: иначе «РЖД» находится внутри «подтве**ржд**ения» (реальный кейс, исправлено).
- Технические отзывы рейтинга (погашение выпуска, истечение срока) → 🔵 инфо, а не 🔴.
- Отзыв по инициативе эмитента → 🟠 с пометкой «уточнить причину».
- Рейтинг отдельного выпуска, а не эмитента →severity понижается.
- «НПФ Сбербанка», «Сбербанк Страхование» и прочие ДЗО помечаются как **связанная структура**.
- Одно и то же сообщение не приходит дважды: дедупликация по хешу заголовка, TTL 21 день.
- Общие названия («Новые технологии», «Казахстан») требуют кредитно-отчётного контекста в той же новости.

## Источники данных

- **MOEX ISS** (`iss.moex.com`) — котировки, история 400 дней, доходности, Z-спред, дюрация, купоны, оферты, номиналы. Без ключей.
- **Yahoo Finance** — Alibaba 9988.HK, курс USD/HKD для пересчёта HKD/RUB (на MOEX пары HKD/RUB нет).
- **АКРА** — пресс-релизы (парсинг списка).
- **Эксперт РА** — страницы релизов за последние 2 дня (список отдаётся JS-ом, поэтому берутся заголовки страниц по датам).
- **Новости:** Интерфакс, РБК, Коммерсантъ (RSS).

## Как запустить

```bash
bash run_morning_check.sh --force        # проверка прямо сейчас
python3 scripts/watch.py --simulate      # тест механики: помеченные [ТЕСТ] алерты
python3 scripts/watch.py --no-telegram   # без отправки
python3 scripts/watch.py --dry-run       # не менять состояние и не отправлять
python3 scripts/scheduler.py --status    # когда следующий плановый запуск
python3 scripts/test_telegram.py         # проверка доставки в Telegram
```

Скрипты работают на **стандартной библиотеке Python 3.11+** — ставить ничего не нужно.
Исключение: `scripts/parse_report.py` (разбор нового PDF) требует `pypdf`.

## Расписание: три варианта

1. **Процесс-планировщик (работает в этой песочнице прямо сейчас)**
   ```bash
   python3 scripts/scheduler.py
   ```
   Спит до ближайшего буднего 10:15 MSK, затем запускает проверку. Если окно уже прошло, а проверки
   сегодня не было — делает догоняющий запуск. Статус: `state/scheduler_status.json`.
   ⚠️ Живёт, пока живёт песочница/сессия. Это не системный cron.

2. **Cron на постоянной машине**
   ```bash
   bash deploy/install_cron.sh
   ```
   Ставит `CRON_TZ=Europe/Moscow` и `15 10 * * 1-5`. Образец: `deploy/crontab.txt`.

3. **systemd-таймер**
   ```bash
   sudo cp deploy/systemd/portfolio-watch.* /etc/systemd/system/
   sudo systemctl daemon-reload && sudo systemctl enable --now portfolio-watch.timer
   systemctl list-timers portfolio-watch.timer
   ```
   `Persistent=true` догонит пропущенный запуск, если машина была выключена.

Выходные пропускаются планировщиком; праздники MOEX — самой проверкой
(сверяется торговая дата ISS, при несовпадении запуск пропускается с записью в лог).

## Подключение Telegram

1. У @BotFather: `/newbot` → токен вида `1234567890:AA...`
2. Написать боту любое сообщение (или добавить в группу).
3. Открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` → взять `result[].message.chat.id`
   (у групп id отрицательный, вида `-100...`).
4. `cp config/secrets.env.example config/secrets.env` и заполнить `TG_BOT_TOKEN`, `TG_CHAT_ID`.
5. `python3 scripts/test_telegram.py` — придёт тестовое сообщение с примерами алертов.

Пока ключей нет, проверка просто пишет отчёт в `reports/` и логирует «Telegram не настроен».

## Обновление портфеля из нового отчёта

```bash
python3 -m venv .venv && .venv/bin/pip install pypdf     # один раз
.venv/bin/python scripts/parse_report.py "uploads/Новый брокерский отчет.pdf"
python3 scripts/build_portfolio.py                     # площадки, номиналы, эмитенты
python3 scripts/make_portfolio_doc.py                  # portfolio.md + portfolio.csv
```

Новые эмитенты автоматически получают ключевые слова из названия; для точности стоит добавить
их в `ISSUERS` в `scripts/build_portfolio.py` (синонимы, ДЗО, латинские написания).

## Ограничения — честно

- Новостной фильтр — **эвристика по ключевым словам**, а не полноценный мониторинг раскрытия.
  Часть событий (НКР, НРА, публикации на сайте эмитента, e-disclosure) может не попасть в ленты.
- Проверка **одна за утро**: внутридневной взлёт после 10:15 будет замечен только на следующее утро.
  Если нужен intraday — можно добавить второй прогон, изменив расписание.
- Объём в 10:15 — это первые минуты сессии, поэтому «всплеск объёма ×4» срабатывает редко;
  он служит подтверждением, а не самостоятельным триггером.
- Заблокированные бумаги (VIPS-RM, FXCN) не оцениваются: котировок нет.
- Отчётность эмитентов проверяется по новостям, а не по прямому разбору МСФО-файлов.
- Это мониторинг, **не инвестиционная рекомендация**.
